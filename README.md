# 리얼워크 일잘러노트 · 멤버 공유버전

GitHub 저장소 이름: `realworker-task`

리얼워크 재직 멤버가 오늘·이번 주·이번 달 할 일을 간단히 기록하고 체크하는 웹 프로토타입입니다. 수습사원이나 온보딩용 앱이 아니라, 이미 함께 일하고 있는 멤버가 일상 업무에 가볍게 쓰는 방향으로 만들었습니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 별도 설치나 빌드 단계가 없습니다. 리얼워크 로고([realwork-logo.png](./realwork-logo.png))와 환영 화면 사진([realwork-team.png](./realwork-team.png))은 `index.html`과 같은 폴더에 둡니다.

## 지금 확인할 수 있는 것

- Supabase 이메일·비밀번호 인증 로그인 화면
- 일잘러노트와 같은 리얼워크 로고, 어두운 기본 테마와 밝은 테마 전환
- 앱에 들어올 때마다 멤버 사진과 만화풍 모션으로 반겨주는 시작 화면(건너뛰기 가능)
- 첫 진입에 시작 순서와 메뉴를 알려주는 튜토리얼(이후 상단 `?`에서 다시 보기)
- 첫 진입 때 시작 순서와 각 메뉴를 안내하는 단계별 튜토리얼(다시 보기는 상단 `?` 버튼)
- 프로필 사진, 입사일, 이름(선택), 요즘 하는 일 프로필
- 오늘의 방향 한 가지와 기억할 키워드 세 가지
- 오늘·주간·월간 날짜별 일정, S/A/B/C 우선순위 수정 및 할 일 제목 편집
- 주간 날짜별 일정 요약(높은 대비와 넉넉한 날짜 칸), 날짜를 선택하면 일정 목록을 확인하고 아래 입력란에서 추가하는 월간 캘린더
- 화면 상단 오늘의 문구: 번갈아 보기/명언/말씀 버튼으로 선택하며 선택을 저장
- 성경 말씀은 퍼블릭 도메인 KJV를 바탕으로 한 절 전체의 한국어 번역과 출처 링크로 표시
- 빠른 메모와 별도 경조사 관리 메뉴(생일, 결혼, 출산, 조사)
- 대시보드 왼쪽의 빠른 메모 입력, 메모장 내 검색 및 일부 내용만 보이는 카드형 목록
- 오늘 대시보드의 일간·주간·월간 통계 요약 제거
- 오늘 대시보드의 경조사 유무 안내
- 앱 관리자에게만 보이는 멤버 초대 메뉴와 초대 이메일 전송
- `.xlsx`, `.xls`, `.csv` 경조사 목록 업로드
- 브라우저 로컬 저장 및 모바일 대응 화면
- 오늘 할 일부터 시작할 수 있으며, 프로필 작성은 선택 사항

## 계정·저장 방식

- 로그인은 Supabase 이메일·비밀번호 인증을 사용하며 공개 회원가입은 꺼져 있습니다. 초대된 멤버만 로그인할 수 있습니다.
- 비밀번호는 앱에서 저장하거나 직접 전송하지 않습니다. Supabase Auth가 인증 세션을 관리합니다.
- 프로필, 사진, 일정, 오늘의 방향·키워드, 메모는 Supabase `member_data`에 계정별로 저장됩니다. Row Level Security(RLS)로 본인 데이터만 읽고 수정할 수 있습니다.
- 멤버 경조사는 `shared_anniversaries`에 저장합니다. 로그인한 멤버는 조회할 수 있고 지정된 앱 관리자만 추가·삭제 및 Excel 가져오기를 할 수 있습니다.
- 이 브라우저에도 계정별 임시 캐시가 저장됩니다. 서버 저장에 실패하면 화면에 오류를 표시합니다.
- 최초 로그인 때 기존 프로토타입 로컬 기록을 해당 계정으로 옮길지 묻습니다. 기존 경조사는 관리자가 팀 공유 목록으로 다시 가져와야 합니다.
- `supabase/schema.sql`은 테이블, RLS 정책, 관리자 권한 검사를 정의합니다. 현재 공개 프런트엔드에는 브라우저용 publishable key만 사용하며, secret/service-role key를 넣으면 안 됩니다.
- Supabase 공개 가입이 꺼져 있으므로 멤버 계정은 앱의 관리자 초대 메뉴나 Supabase 대시보드에서 이메일 초대로 만듭니다. 관리자 지정은 Supabase에서 별도로 진행합니다.
- 앱에서 보내는 멤버 초대는 `supabase/functions/invite-member` Edge Function을 사용합니다. 함수는 로그인 세션과 `is_app_admin()` 권한을 서버에서 확인한 뒤 초대하며, 초대된 계정은 일반 멤버입니다. 관리자 권한은 자동 부여되지 않습니다.
- Edge Function은 `supabase functions deploy invite-member --project-ref ztwctxsddydkdblgubbj`로 배포하고, Supabase Function Secrets에 `INVITE_ALLOWED_ORIGINS`를 실제 앱의 정확한 origin(예: `https://realworker-task-r6na2f096-yeinvisions-projects.vercel.app`)으로 등록해야 합니다. Supabase의 함수 기본 환경 변수로 제공되는 service-role key는 서버 함수에서만 사용합니다.
- 단일 정적 HTML이므로 Supabase URL과 publishable key는 `index.html`에 포함됩니다. 데이터 보안은 비밀 키가 아니라 RLS 정책에 의존합니다.
- 말씀은 퍼블릭 도메인 KJV를 바탕으로 절 전체를 한국어로 옮긴 비공식 자체 번역이며, 각 절의 KJV 출처를 연결합니다.
- 경조사 Excel 권장 열은 `멤버명`, `날짜`, `종류`입니다. 생일 날짜는 `월/일`도 가능하며 매년 표시합니다. 다른 경조사는 연도를 포함해 입력하고 해당 날짜에 한 번 표시합니다. 입사 기념일은 가져오지 않습니다.
- Excel은 브라우저에서 읽고 경조사 관리자 권한으로 Supabase에 저장합니다. 파일 원본은 업로드하지 않습니다.
- Excel을 처음 선택할 때 SheetJS를 CDN에서 불러옵니다. 파일 내용은 SheetJS로 브라우저 안에서 처리합니다.
